1

Ce este HTML-ul?

HTML (HyperText Markup Language) este un limbaj de marcare ce poate fi utilizat pentru a crea structura unei pagini web, pentru a încărca resurse sau pentru a controla comportamentul browser-ului.

2

Editoare de cod

În principal folosim Visual Studio Code pentru a edita cod manual deoarece este cel mai bine dotat editor, dar există și variante precum Notepad++ sau Notepad, sau chiar Cursor sau alte asemenea aplicații pentru editoare moderne de cod care au integrate inteligența artificială.

3

Execuția codului

Pentru a vedea rezultatul codului, deschidem output-ul (fișierul HTML) în browsere compatibile precum Chrome, Edge, Firefox, Brave etc. Mai există variante precum hosting-ul public pentru a publica site-ul pe internet, dar și servere locale pentru a testa în rețea site-ul web.

4

Structura paginii

O pagină generică pur HTML conține următoarele secțiuni:

  • Antet: este partea pur invizibilă care conține resurse, instrucțiuni pentru browser, librării și tag-uri de customizare de bază.
  • Corp: conține codul sursă al site-ului în sine, unde putem găsi texte, elemente, imagini și așa mai departe.
<!DOCTYPE html>
<html lang="en">
<head>
    <title>Website</title>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
</head>
<body>
    <p>Hello World!</p>
</body>
</html>
5

Elementele limbajului

a Cum se adaugă texte (paragrafe, titluri)

Utilizăm elementul <p> pentru a adăuga texte sau paragrafe în pagină. Mai folosim și <hx> pentru adăugarea titlurilor în pagină, de la 1 la 6.

<p>Hello World!</p>
<h1>Hello World!</h1>
<h2>Hello World!</h2>
<h3>Hello World!</h3>
<h4>Hello World!</h4>
<h5>Hello World!</h5>
<h6>Hello World!</h6>

b Link-uri

Utilizăm elementul <a> pentru a adăuga link-uri în pagină (ancoră). În href punem link-ul propriu-zis.

<a href="#">Hello World!</a>

c Imagini

Utilizăm elementul <img> pentru a adăuga imagini în pagină. Folosim src pentru calea către imagine și alt pentru textul alternativ.

<img src="image.jpg" alt="Hello World!">

d Liste (ordonate, neordonate)

Utilizăm elementul <ul> pentru liste neordonate (cu buline) și <ol> pentru liste ordonate (numerotate). Fiecare element din listă se pune în <li>.

<ul>
    <li>Hello</li>
    <li>World!</li>
</ul>

<ol>
    <li>Hello</li>
    <li>World!</li>
</ol>

e Tabele

Utilizăm elementul <table> pentru a adăuga tabele în pagină. Rândurile se pun în <tr>, celulele de antet în <th>, iar celulele obișnuite în <td>.

<table>
    <tr>
        <th>Nume</th>
        <th>Vârstă</th>
    </tr>
    <tr>
        <td>Andrei</td>
        <td>20</td>
    </tr>
</table>

f Formulare

Utilizăm elementul <form> pentru a crea formulare. În interior punem câmpuri precum <input>, etichete cu <label> și un buton de trimitere cu <button>.

<form action="#" method="post">
    <label for="nume">Nume</label>
    <input type="text" id="nume" name="nume">

    <label for="email">Email</label>
    <input type="email" id="email" name="email">

    <button type="submit">Trimite</button>
</form>

g Sunet / Video

Utilizăm elementul <audio> pentru sunet și <video> pentru video. Atributul controls afișează butoanele de redare, iar în src punem calea către fișier.

<audio src="sunet.mp3" controls></audio>

<video src="video.mp4" width="640" controls></video>

h Zone în pagini (div)

Utilizăm elementul <div> pentru a grupa alte elemente în zone ale paginii. Prin class sau id putem stiliza fiecare zonă separat din CSS.

<div class="zona">
    <h2>Hello World!</h2>
    <p>Hello World!</p>
</div>
